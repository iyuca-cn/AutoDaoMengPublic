# DMAPI CLI Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an isolated CLI for directly using the existing `DMAPI` wrapper.

**Architecture:** Add a new `src/dmapi_cli/` package that owns argument parsing, output formatting, command dispatch, confirmations, and exit codes. It reuses `DMAPI` for service startup, login state, config, and API behavior, and does not alter the existing business workflow CLI.

**Tech Stack:** Python 3.12, argparse, json, pathlib, pytest, existing `src/DMAPI`.

---

## File Structure

- Create: `src/dmapi_cli/__init__.py`
  - Package marker.
- Create: `src/dmapi_cli/output.py`
  - Text summary helpers and JSON serialization helpers.
- Create: `src/dmapi_cli/main.py`
  - CLI parser, command dispatch, confirmation handling, DMAPI invocation, and exit codes.
- Create: `tests/test_dmapi_cli.py`
  - Unit tests for parser, command mapping, output, confirmations, and file export.
- Modify: `readme.md`
  - Add a short usage section for the new direct DMAPI CLI.
- Modify: `docs/到梦空间python API.md`
  - Link the new CLI and clarify it reuses `DMAPI`.

## 配置文件

当前默认配置文件名为 `config.ini`，首次运行会按登录流程自动创建或补全。`src/main.py` 和 `src/dmapi_cli/main.py` 默认都会使用这个文件；DMAPI CLI 可通过全局参数 `--config` 指定其他配置文件。

示例结构：

```ini
[login]
account = 手机号/身份证号
pwd = 密码
uid = 用户ID
token = 登录令牌

[local_server]
base_url = http://127.0.0.1:8765
exe_path = E:\path\to\dmlocalapi_server.exe
```

## `[login]`

- `account`：账号登录时使用的手机号或身份证号。
- `pwd`：账号密码。
- `uid`：登录成功后缓存的用户 ID。
- `token`：登录成功后缓存的登录态令牌。

说明：

- 当本地存在有效 `uid/token` 时，程序会优先尝试复用登录态。
- 如果登录态失效，程序会提示重新登录，或让你粘贴“管理活动 -> 人员管理 -> 导出”后跳到浏览器的 URL 来导入手机登录态。
- 成功登录后，程序会自动把最新的 `uid/token/account/pwd` 写回 `config.ini`。

## `[local_server]`

- `base_url`：已启动本地服务的地址，例如 `http://127.0.0.1:8765`。
- `exe_path`：`dmlocalapi_server.exe` 的绝对路径，可选。

说明：

- 当前版本已不再使用旧的 `[crypto_api]` 配置段。
- 如果没有配置 `base_url`，客户端默认会尝试访问或启动 `http://127.0.0.1:8765`。
- 如果设置了 `base_url` 且未禁用自动启动，程序会优先复用该地址；该地址不可用时，会尝试在相同端口或默认端口附近启动本地服务。
- 如果没有配置 `exe_path`，程序会按下面顺序查找 `dmlocalapi_server.exe`：
  - `DMLOCALAPI_SERVER_EXE` 环境变量指定路径
  - 当前入口脚本同目录，例如 `src/` 或 `src/dmapi_cli/`
  - 当前工作目录
  - `src/DMAPI/`
  - `src/dist/`
- 本地运行时通常把可执行文件放在 `src/dist/dmlocalapi_server.exe`；由于 `.gitignore` 忽略 `*.exe` 和 `dist/`，克隆仓库后如果文件缺失，需要手动下载后放入本地。

## 环境变量优先级

本地服务相关配置遵循“环境变量优先于配置文件”的原则：

- `DMLOCALAPI_BASE_URL`：覆盖 `[local_server].base_url`
- `DMLOCALAPI_SERVER_EXE`：覆盖 `[local_server].exe_path`
- `DMLOCALAPI_DISABLE_AUTOSTART=1`：禁止自动拉起本地服务

补充说明：

- 禁止自动启动后，客户端只会按 `DMLOCALAPI_BASE_URL`、`[local_server].base_url` 或默认 `http://127.0.0.1:8765` 连接既有服务，不会帮你启动 `dmlocalapi_server.exe`。
- 自动启动未禁用时，如果首选端口不可用，程序会从默认端口 `8765` 起尝试后续端口，直到找到可用端口或超过搜索范围。

## 安全建议

- `config.ini` 保存的是明文账号、密码和登录态，请勿提交、转发或截图外传。
- 当前仓库的 `.gitignore` 已忽略 `*.ini`，但本地备份、聊天记录和压缩包同样可能泄露敏感信息。
